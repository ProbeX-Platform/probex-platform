# ProbeX

Open-source runtime debugger for Node.js: non-breaking breakpoints and snapshots in running applications.

> Early development. APIs are not stable yet.

## Quick start

```sh
pnpm install
pnpm verify
```

Requires Node.js ≥ 22 and pnpm 10.
