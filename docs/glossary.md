# Glossary

One name per concept. Use these terms in code, docs and issues; add a term here before using a new one.

| Term      | Meaning                                                                            |
| --------- | ---------------------------------------------------------------------------------- |
| SDK       | The `@probex/sdk` package running inside the host app.                             |
| Host app  | The user's Node.js application that embeds the SDK.                                |
| Connector | The `@probex/connector` package that carries messages between the SDK and clients. |
| ADR       | Architecture decision record in `docs/adr/`.                                       |
